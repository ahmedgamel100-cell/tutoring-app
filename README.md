# 📚 دروس أونلاين — نظام إدارة الدروس

## تشغيل محلي (على جهازك)

```bash
npm install
npm start
```

افتح المتصفح على: http://localhost:3000

---

## نشر على Railway (مجاني)

### الخطوات:

1. **أنشئ حساب على GitHub** (لو مش عندك)
   → https://github.com

2. **ارفع الكود على GitHub:**
   ```bash
   git init
   git add .
   git commit -m "first commit"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/tutoring-app.git
   git push -u origin main
   ```

3. **أنشئ حساب على Railway:**
   → https://railway.app
   → سجّل دخول بحساب GitHub

4. **أنشئ مشروع جديد:**
   → اضغط "New Project"
   → اختار "Deploy from GitHub repo"
   → اختار الـ repo اللي رفعته

5. **أضف Volume للبيانات (مهم!):**
   → في الـ project، اضغط على الـ service
   → اضغط "Volumes"
   → أضف Volume واربطه بـ `/app/data`
   → في Settings → Environment Variables أضف:
     ```
     DB_PATH=/app/data/data.db
     ```

6. **Railway هيديك رابط تلقائياً** زي:
   `https://tutoring-app-production-xxxx.railway.app`

## كلمة السر (مهم لو البرنامج على النت)

في Railway → Settings → Environment Variables ضيف:
```
APP_PASSWORD=كلمة-سر-قوية
```
المتصفح هيطلب اسم مستخدم (اكتب أي حاجة) وكلمة السر دي.

## نقل البيانات من ملف الإكسل القديم

الإعدادات → **استيراد من ملف Excel القديم** → اختار الملف (`.xlsm` أو `.xlsx`).

- **شيتات المدرسين** (اللي فيها Group Name / Deal / All Sessions): كل شيت بيبقى مدرس، وكل صف بيبقى مجموعة بمدفوعاتها وحصص المدرس.
- **شيتات سجل التحويلات** (كاش / بنك / اسم الطالب / التاريخ): بتدخل في سجل المدفوعات بتواريخها، ومعاها اسم المرسل و"وصل" و"اتسجل".
- شيتات `Blank` (النماذج الفاضية) بتتساب.

## طريقة الحساب (نفس الإكسل)

| البند | الحساب |
|---|---|
| سعر الحصة على الطالب | سعر الباقة ÷ عدد الحصص |
| إجمالي المدفوع (ريال) | بنك + كاش + (محفظة بالجنيه ÷ سعر الصرف) |
| المتبقي على الطالب | سعر الباقة − إجمالي المدفوع |
| الحصص المتبقية | عدد الحصص − الحصص اللي اتدفعت للمدرس |
| اتدفع للمدرس (جنيه) | الحصص اللي اتدفعت × سعر حصة المدرس |
| صافي ولاء (جنيه) | (إجمالي المدفوع × سعر الصرف) − اللي اتدفع للمدرس |
| سعر الصرف | سعر الدولار بالجنيه ÷ سعر الدولار بالريال (48.25 ÷ 3.65) |
